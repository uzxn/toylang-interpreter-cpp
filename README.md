# toylang-interpreter-cpp

A tiny interpreter for a toy language, written in C++

ToyLang 是一个小型语言的解释器，使用 C++ 实现。它支持变量、数组、算术运算、逻辑运算、输入输出、代码块、条件分支和循环等基本功能。解释器采用递归下降解析，将源代码解析为 AST 后直接求值。

## 特性

- 零元、一元、二元指令
- 代码块 `{ }`，可将多条语句组合成一条语句
- 变量与数组操作
- 算术运算：`add`、`sub`、`mul`、`div`、`mod`
- 比较运算：`gre`、`les`、`eq`
- 逻辑运算：`and`、`or`、`not`（`and`、`or` 支持短路求值）
- 位运算：`&`、`|`、`^`、`~`、`<<`、`>>`
- 输入输出：`in`、`cin`、`vin`、`out`、`cout`
- 控制流：`if`、`while`、`break`、`continue`
- 单文件实现，无需第三方依赖

## 快速开始

### 编译

使用支持 C++17 的编译器如 `g++`：

```bash
g++ -std=c++17 -O2 toylang.cpp parse.cpp eval.cpp -o toylang
```

源码结构：

- `toylang.cpp`：程序入口，读取源文件并驱动解析与执行
- `parse.cpp`：词法 token 的解析，构造语法树
- `eval.cpp`：语法树求值
- `toylang.h`：共享的类型声明与接口

### 运行

```bash
./toylang program.tl
```

其中 `program.tl` 是 ToyLang 源文件。

## 语言参考

### 词法

- 程序由空白字符（空格、换行、制表符）分隔的 token 组成。
- 数字：必须是只由数字字符组成的非负整数；含其他字符或超出整数范围时报错；不支持负数字面量。
- 变量：以 `$` 开头，例如 `$x`。
- 代码块：`{` 和 `}` 必须作为独立的 token。
- 不支持标签和注释。

### 语句返回值

所有语句都返回一个整数，供外层语句作为参数使用：

- 数字返回其本身；变量返回其当前值（未赋值的变量为 0）。
- 赋值语句 `set` 返回赋的值。
- `out`、`cout`、`aset` 返回 1。
- `while` 返回循环体执行的次数。
- 其余指令按语义返回结果。

### 零元指令

| 指令        | 说明                                               |
| ----------- | -------------------------------------------------- |
| `in`        | 从标准输入读取一个整数                             |
| `cin`       | 从标准输入读取一个字符（包括空白）                 |
| `vin`       | 从标准输入读取一个可见字符（跳过空白）             |
| `break`     | 结束所在的 `while` 循环，返回 0                    |
| `continue`  | 跳过本次循环剩余部分，进入下一次条件判断，返回 0   |

`break` 和 `continue` 只在 `while` 循环体内有意义；出现在循环外时会被忽略。

### 一元指令

| 指令    | 说明                                            |
| ------- | ----------------------------------------------- |
| `not`   | 逻辑非，操作数为 0 返回 1，否则返回 0           |
| `~`     | 按位取反                                        |
| `out`   | 输出操作数的整数值，返回 1                      |
| `cout`  | 输出操作数对应的 ASCII 字符（0 到 127），返回 1 |

### 二元指令

| 指令  | 说明                                      |
| ----- | ----------------------------------------- |
| `add` | 加法                                      |
| `sub` | 减法                                      |
| `mul` | 乘法                                      |
| `div` | 除法（除数为 0 时输出错误并返回 0）       |
| `mod` | 取模（除数为 0 时输出错误并返回 0）       |
| `gre` | 大于，返回 1 或 0                         |
| `les` | 小于，返回 1 或 0                         |
| `eq`  | 等于，返回 1 或 0                         |
| `and` | 逻辑与（短路），返回 1 或 0               |
| `or`  | 逻辑或（短路），返回 1 或 0               |
| `&`   | 按位与                                    |
| `\|`  | 按位或                                    |
| `^`   | 按位异或                                  |
| `<<`  | 左移，移位数须在 0 到 63 之间             |
| `>>`  | 右移，移位数须在 0 到 63 之间             |

位运算按 64 位整数执行；`<<`、`>>` 的移位数超出 0 到 63 时输出错误并返回 0。

### 赋值语句

| 语句          | 说明                           |
| ------------- | ------------------------------ |
| `set $var expr` | 将变量设为表达式的值，返回该值 |

### 数组操作

| 指令                        | 说明                                                     |
| --------------------------- | -------------------------------------------------------- |
| `aset $arr index value`     | 设置数组元素，索引从 0 开始，自动扩容；返回 1            |
| `aget $arr index`           | 获取数组元素；数组未定义或索引越界时输出错误并返回 0     |
| `alen $arr`                 | 获取数组长度；数组未定义时返回 0                         |

### 控制流

| 语句                    | 说明                                                     |
| ----------------------- | -------------------------------------------------------- |
| `if condition body`     | 若 condition 非 0，则执行 body 并返回其结果，否则返回 0  |
| `while condition body`  | 当 condition 非 0 时重复执行 body，返回执行的次数        |
| `{ stmt1 stmt2 ... }`   | 依次执行多条语句，返回最后一条语句的返回值               |

### 错误处理

- 解析期错误（无法识别的 token、缺少参数、非法数字、变量名缺少 `$` 前缀）会输出 `invalid token: <token>`、`invalid number: <token>` 等错误信息，程序以退出码 1 结束。
- 运行期错误（除零、数组越界、非法的 `cout` 参数、`in` 读到非法整数或输入结束等）输出到标准错误，并返回 0 继续执行。

### 示例

#### 输入两个整数并输出它们的和

```
out add in in
```

#### 判断一个整数的奇偶

```
set $i in
if { eq mod $i 2 0 } {
    cout 65
    cout 10
}
if { eq mod $i 2 1 } {
    cout 66
    cout 10
}
```

更多示例程序请参考 `examples/` 目录：

- `selection_sort.tl`：输入一个整数 n 以及 n 个整数，输出这 n 个数排序后的结果。使用选择排序算法，循环由 `while` 实现。
- `quick_sort.tl`：输入一个整数 n 以及 n 个整数，输出升序排序结果。使用快速排序算法，用数组模拟显式栈来替代语言不支持的递归。
- `fenwick_tree.tl`：树状数组。先输入 n 与 n 个整数建树，再输入 q 条操作：`1 pos delta` 表示在 pos 处增加 delta，`2 pos` 表示输出前 pos 个数的和。
