# toylang-interpreter-cpp

A tiny interpreter for a toy language, written in C++

ToyLang 是一个小型语言的解释器，使用 C++ 实现。它支持变量、数组、算术运算、逻辑运算、输入输出、条件分支和跳转等基本功能。解释器采用递归下降解析，将源代码解析为 AST 后直接求值。

## 特性

- 零元、一元、二元指令
- 变量与数组操作
- 算术运算：`add`、`sub`、`mul`、`div`、`mod`
- 比较运算：`greater`、`less`、`equal`
- 逻辑运算：`and`、`or`、`not`（支持短路求值）
- 输入输出：`inputNum`、`inputChar`、`inputVis`、`print`、`printChar`
- 控制流：`if`、`goto` 和标签
- 单文件实现，无需第三方依赖

## 快速开始

### 编译

使用支持 C++17 的编译器如 `g++`：

```bash
g++ -std=c++17 -O2 toylang.cpp -o toylang
```

### 运行

```bash
./toylang program.tl
```

其中 `program.tl` 是 ToyLang 源文件。

## 语言参考

### 词法

- 程序由空白字符（空格、换行、制表符）分隔的 token 组成。
- 数字：以数字开头，解析为整数。
- 变量：以 `$` 开头，例如 `$x`。
- 标签：以 `:` 结尾，例如 `loop:`。
- 注释：不支持。

### 指令

#### 零元指令

| 指令        | 说明                                   |
| ----------- | -------------------------------------- |
| `inputNum`  | 从标准输入读取一个整数                 |
| `inputChar` | 从标准输入读取一个字符（包括空白）     |
| `inputVis`  | 从标准输入读取一个可见字符（跳过空白） |

#### 一元指令

| 指令        | 说明                                    |
| ----------- | --------------------------------------- |
| `not`       | 逻辑非，操作数为 0 返回 1，否则返回 0   |
| `print`     | 输出操作数的整数值                      |
| `printChar` | 输出操作数对应的 ASCII 字符（0 到 127） |

#### 二元指令

| 指令      | 说明                    |
| --------- | ----------------------- |
| `add`     | 加法                    |
| `sub`     | 减法                    |
| `mul`     | 乘法                    |
| `div`     | 除法（除数为 0 时报错） |
| `mod`     | 取模（除数为 0 时报错） |
| `greater` | 大于，返回 1 或 0       |
| `less`    | 小于，返回 1 或 0       |
| `equal`   | 等于，返回 1 或 0       |
| `and`     | 逻辑与（短路）          |
| `or`      | 逻辑或（短路）          |

#### 变量操作

| 指令               | 说明                 |
| ------------------ | -------------------- |
| `set $var expr`    | 将变量设为表达式的值 |
| `addSet $var expr` | 变量增加表达式的值   |
| `subSet $var expr` | 变量减去表达式的值   |
| `mulSet $var expr` | 变量乘以表达式的值   |
| `divSet $var expr` | 变量除以表达式的值   |
| `modSet $var expr` | 变量对表达式的值取模 |

#### 数组操作

| 指令                       | 说明                                  |
| -------------------------- | ------------------------------------- |
| `arraySet $arr index expr` | 设置数组元素，索引从 0 开始，自动扩容 |
| `arrayGet $arr index`      | 获取数组元素                          |
| `arrayLen $arr`            | 获取数组长度                          |

#### 控制流

| 指令                | 说明                                  |
| ------------------- | ------------------------------------- |
| `if condition then` | 若 condition 非 0，则执行 then 表达式 |
| `goto label`        | 跳转到标签处                          |
| `label:`            | 定义标签，标签指向下一条语句          |

### 示例

#### 输入两个整数并输出它们的和

```
print add inputNum inputNum
```

更多示例程序请参考 `examples/` 目录：

- `selection_sort.tl`：输入一个整数 n 以及 n 个整数，输出这 n 个数排序后的结果。使用选择排序算法。
